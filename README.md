# FitBuddy – AI

A responsive fitness dashboard and AI-assistant demo suitable for a college mini project.

## Features
- Fitness dashboard
- Daily workout checklist
- AI-style fitness recommendations
- Nutrition/meal guide
- Chat-style FitBuddy assistant
- Responsive mobile layout
- No installation required

## Run
1. Download/extract the project.
2. Open `index.html` in Chrome/Edge.
3. For development, VS Code + Live Server can be used.

## AI integration
The current assistant uses simple JavaScript responses so the project works offline.
For a real AI version, replace `aiReply()` in `script.js` with a secure backend API call to Gemini/OpenAI. Never expose a private API key directly in browser JavaScript.

## Suggested college-project modules
1. User profile
2. Workout planner
3. Nutrition assistant
4. Progress tracking
5. AI fitness chatbot
6. Admin/database module (optional)

## Note
This is an educational project. Fitness recommendations should not replace advice from a qualified healthcare professional.
